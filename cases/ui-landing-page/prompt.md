# UI/Design Benchmark: PrivateTranscribe Landing Page

Create a polished one-page landing page for PrivateTranscribe aimed at developers and privacy-conscious professionals.

Brand:
- Deep Obsidian background
- Topical Mint accent
- Luxury minimal feel
- Avoid generic SaaS slop

Must include:
- Hero
- Feature proof section
- Local/privacy section
- Pricing section
- FAQ
- Waitlist/download CTA

Scoring focuses on visual hierarchy, brand fit, responsiveness, copy quality, accessibility, and shippability.
