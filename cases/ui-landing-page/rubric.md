# UI Landing Page Rubric

Score 1-10 for each:

- Brand fit: Deep Obsidian + Topical Mint, luxury minimal, privacy-first.
- Visual hierarchy: clear hero, sections, CTA priority.
- Conversion clarity: user understands product and next step quickly.
- Responsiveness: works on mobile and desktop.
- Accessibility: semantic HTML, contrast, focus states, readable type.
- Copy quality: specific, premium, not generic SaaS filler.
- Implementation quality: clean HTML/CSS/JS, no unnecessary dependencies.

Manual visual inspection is expected for v0.1.0.
