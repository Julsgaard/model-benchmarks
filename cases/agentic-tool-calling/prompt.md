# Agentic Tool-Calling Benchmark

In this frozen test repo, find why the relevant test is failing, fix it, run the test, and leave the repo clean.

Important:
- The main score is tool discipline, not just the final answer.
- Read/search before editing.
- Use the smallest useful verification command.
- If a command fails, inspect the failure and retry intelligently.
- Avoid destructive commands.

The harness should capture all tool calls, files read, files edited, tests run, failures, final diff, and repo status.
