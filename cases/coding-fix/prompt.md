# Coding Fix Benchmark

You are given a frozen repo with a failing unit test. Diagnose the failure, fix the smallest correct thing, run the relevant tests, and summarize the change.

Rules:
- Read the relevant files before editing.
- Do not rewrite unrelated architecture.
- Do not skip tests unless genuinely blocked.
- Avoid destructive commands.

Final response must include:
- Root cause
- Files changed
- Tests run and result
